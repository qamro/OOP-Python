# OOP-Python

A collection of Python exercises and mini-projects focused on Object-Oriented Programming concepts.

## Topics Covered
- Classes & Objects
- Inheritance
- Encapsulation
- Polymorphism
- Abstraction
- Magic methods 
- @Decorators
## Getting Started
```bash
git clone https://github.com/qamro/OOP-python.git
cd OOP-python
python main.py
```

## Requirements
- Python 3.x
